Basic Text Analyzer in Python

Hello! This is a simple Python script that analyzes a text entered by the user, providing useful information about its content. It's perfect for beginners looking for a practical example of how to handle strings, lists, and dictionaries in Python.

Features
- This script performs the following tasks:

- Letter Count: Asks the user for three letters of their choice and counts how many times they appear in the text.

- Word Count: Counts the total number of words in the text.

- Letter Identification: Shows the first and last letters of the text.

- Reversed Text: Reverses the order of the words in the text and displays it.

- Word Search: Checks if the word 'Python' is present in the text.

- Requirements
To run this script, you only need to have Python 3 installed on your system.

Usage
- Clone this repository or download the analizador_texto.py file.

- Open a terminal or command prompt.

- Navigate to the directory where the file is located.

- Run the script with the following command:

      Bash
    
      python TextAnalyzr.py

- Follow the on-screen instructions to enter your text and the three letters you want to analyze.

Example of Interaction

    Enter any text: Hello world, this is an example of text.
    
    Next, enter 3 letters of your choice:
    Enter the first letter: o
    Enter the second letter: e
    Enter the third letter: x
    
    
    The number of letters are:
    Found 'o' repeated 4 times
    Found 'e' repeated 6 times
    Found 'x' repeated 1 times
    
    
    Word count:
    A total of 7 words were found in the text you entered
    
    
    First and last letter:
    The starting letter is 'h' and the ending letter is 't'
    
    
    Reversed text
    Your reversed text will say: 'text. of example an is this world, hello'
    
    
    Is Python here?
    The word 'Python' is not in the text
